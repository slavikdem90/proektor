# Интерактивная проекция (для себя, побаловаться)

Проектор светит на полотно, камера смотрит на полотно, программа видит попадание мячом и меняет картинку. Обсуждали 17.11.2026, дальше работаем в отдельной сессии.

## Решено
- Делаем для себя, не на продажу. На прототип отводим один вечер: понравится — продолжаем, нет — бросаем.
- Программа — страница в браузере на маке, как эквалайзер. Без нейросетей: классическое сравнение кадров.
- Первая версия: калибровка кликами по 4 меткам в углах, игра «Шарики» (попал мячом — шарик лопается, очки).
- Лук пока не трогаем: без щита опасно для стены и проектора.

## Камера
1. Основной вариант: Insta360 ONE R с модулем 4K Wide Angle. Режим веб-камеры: Общие → Режим USB → WebCam, нужна прошивка от 1.2.15 и кабель USB 3.0. Отдаёт 1080p, частота кадров неизвестна (скорее всего 30).
   - Риск: в режиме веб-камеры может сама менять зум, держа людей в кадре. Это сломает калибровку. Пользователь проверяет на месте.
2. Запасной: iPhone как камера Continuity.
3. Последний: Sony FDR-X3000 через micro-HDMI и USB-карту захвата (3–6 тыс. ₸, нужен 1080p60). По USB видео не отдаёт.

Камеру лучше ставить рядом с проектором, примерно на одной линии.

## Известные трудности
- Камера видит саму проекцию и путает её с движением. Если ложных срабатываний много, следующий шаг — ИК-камера с ИК-подсветкой.
- Момент касания мяча обычная камера видит плохо. Надёжно ловит лидар в плоскости перед полотном или камера 120+ кадров в секунду.

## Прототип (17.11.2026)
`index.html` — открыть в Chrome. Калибровка по 4 меткам, сравнение соседних кадров на сетке 128×72 в координатах экрана, самое крупное пятно движения считается попаданием. Зоны, где идёт анимация (появление и лопание шарика), временно не учитываются. Калибровка и настройки сохраняются в браузере.

## Сцены (18.11.2026)
Стрелки ← → переключают сцены, у каждой свой счёт. «Шарики» (+1, фон тёмный/белый/небо, клавиша B) и «Сокровищница»: хранилище с ячейками и дверью сейфа, монеты +10, изредка рубин +50 на 7 секунд. Фоны статичные, иначе камера видит в них движение. Табло и точки сцен исключены из распознавания, во время перелистывания распознавание выключено.

## Следующий шаг
Пользователь пробует прототип на месте с ONE R и подбирает порог и размер пятна. По результату решаем: продолжать, бросить или переходить на ИК.
